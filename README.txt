Drucilog's Playground Patcher

Download:
https://dandrews2930.github.io/drucilogs_playerground/drucilogpatcher.exe

How to use:
1. Put drucilogpatcher.exe in your EverQuest RoF2 folder.
2. Run drucilogpatcher.exe.
3. Click Patch.
4. Start EverQuest normally after patching finishes.

The patcher updates server files such as spells_us.txt, dbstr_us.txt,
eqstr_us.txt, GlobalLoad_chr.txt, eqhost.txt, and dinput8.dll.

If Windows warns about the file, choose to keep/run it because this is a
custom server patcher.
